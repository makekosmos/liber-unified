# Статус Liber на NSH

Ветка: `hayro-pdf`

## Сделано

- NSH стал приложением в корне репозитория: манифест `nsh.json`, crate в корневом `Cargo.toml`, UI в `src/lib.rs`. Каталог `nsh-app` удалён, параллельная GPUI-версия из исходников удалена.
- PDF, библиотечное хранилище и поиск по названию/автору вынесены в UI-независимый crate `crates/liber-core`. NSH использует его для импорта, рендера hayro, текстового слоя, outline и прогресса чтения.
- Библиотека показывает карточки с реальными обложками и прогрессом. Импорт проверяет дубликаты по байтам, копирует PDF в локальное хранилище и сохраняет обложку. Работает системный диалог выбора PDF.
- Ридер показывает bitmap hayro, текстовую панель, навигацию страниц и кликабельные пункты PDF outline. Светлая/тёмная тема сохраняется; тёмный режим инвертирует bitmap страницы.
- Скриншот Windows окна на `C:\Users\kirill\Downloads\Frontend-разработчик.pdf`: `target\liber-nsh.png`.
- Стабильный этап переноса в NSH закоммичен: `c56d712 Move Liber UI to root NSH application`.

## Проверки

- `cargo build` — успешно; 8 предупреждений о возможностях PDF navigation, не подключённых к UI.
- `cargo test` — 2 passed, 0 failed.
- `nsh test` — 1 passed, 0 failed.
- `nsh run --target windows` — runner собран и запущен из корня. Проверен реальный импорт PDF из Downloads: файл оказался в `%APPDATA%\Liber\books`, обложка — в `%APPDATA%\Liber\covers`.
- Для автоматического открытия тестового файла при запуске можно задать `LIBER_OPEN_PDF`; обычный импорт выполняется через **Добавить PDF**.

## Оставшаяся работа

- Сравнение выполнено по GPUI-исходникам из предыдущего коммита, отдельный снимок GPUI-окна не сохранён. Общая компоновка библиотеки и ридера повторена, но пиксельного совпадения нет: пока отличаются палитры и типографика; отсутствуют настройки темы GPUI, поиск по тексту PDF, выделения, заметки, reflow и дополнительные панели/toolbar-состояния.
- Корневой тест проверяет стартовый экран. Нет UI-тестов импорта, перелистывания, перехода по outline и смены темы.
- Обложки сейчас рендерятся в исходном размере страницы; плиточная отрисовка hayro и повторное использование render cache между страницами не подключены.

## Запуск из корня

```powershell
nsh run --target windows
```

Нажмите **Добавить PDF** и выберите файл. Книги, прогресс и тема сохраняются в `%APPDATA%\Liber`.
