# Статус Liber на NSH

Ветка: `hayro-pdf`

## Сделано

- NSH стал приложением в корне репозитория: манифест `nsh.json`, crate в `Cargo.toml`, UI в `src/lib.rs`. Папки `nsh-app` больше нет.
- Основной запуск и сборка NSH идут из корня. Окно: библиотека с карточками, навигационная панель, системный диалог выбора PDF, ридер с hayro-рендером страниц, текстовый слой, переключение светлой/тёмной темы и сохранение прогресса чтения.
- Подключён разбор PDF outline через существующий `src/pdf_nav.rs`; если в PDF нет оглавления, панель остаётся пустой. Текстовый слой показывается отдельно от изображения.
- Добавлен smoke test NSH для корневого экрана. Старые GPUI UI-модули и параллельное приложение удалены.
- Реальный Windows запуск проверен на `C:\Users\kirill\Downloads\Frontend-разработчик.pdf`. Снимок окна: `target\liber-nsh.png`.

## Проверки

- `cargo build` — успешно, 9 предупреждений о неиспользуемых возможностях PDF navigation.
- `cargo test` — успешно, Rust-тестов в новом crate пока нет.
- `nsh test` — 1 passed, 0 failed.
- `nsh run --target windows` — runner собран и запущен из корня.
- Для передачи PDF прямо при старте можно установить `LIBER_OPEN_PDF`; обычный способ — **Добавить PDF** и системный диалог.

## Ещё не перенесено

- Полная логика GPUI Liber не вынесена в отдельный общий crate. Нынешние библиотека и прогресс реализованы заново в NSH crate; поиск по библиотеке/книге, заметки и выделения, reflow, переходы по оглавлению, сортировка/фильтры, сетевые метаданные и полноценное хранилище копий PDF ещё не перенесены.
- Обложки книг пока placeholder; карточки не совпадают с GPUI по деталям. NSH-версия повторяет общую компоновку и базовую палитру, но не все цвета, шрифты, отступы, toolbar-анимации и состояния оригинала.
- Ночная тема инвертирует изображение страницы; отдельные режимы Day/Sepia/Gray/Night и выбор палитр GPUI ещё не перенесены.
- Скриншот снят с NSH-окна. GPUI-версия была сопоставлена по исходной реализации в `044a931`; отдельный скриншот GPUI в этом этапе не сохранён.
- На PDF без текстового слоя отображается сообщение, что текста нет. Текстовый слой пока не синхронизирован с прокруткой страницы и не поддерживает выбор.

## Запуск из корня

```powershell
nsh run --target windows
```

Нажмите **Добавить PDF** и выберите файл. Ридер открывается из карточки книги; прогресс и тема сохраняются в `%APPDATA%\Liber`.
