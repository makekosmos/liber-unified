# Статус Liber на NSH

Ветка: `hayro-pdf`

## Сделано

- NSH стал приложением в корне репозитория: `nsh.json`, корневой `Cargo.toml`, UI в `src/lib.rs`. Каталог `nsh-app` и старая параллельная GPUI-реализация удалены.
- PDF, библиотечное хранилище и поиск вынесены в независимый UI crate `crates/liber-core`; корневое приложение вызывает его для импорта, hayro-рендера, извлечения текста, outline, прогресса и поиска по содержимому PDF.
- Библиотека показывает реальные обложки и прогресс. Импорт через системный file picker копирует PDF в локальное хранилище и не добавляет повторно файл с теми же байтами. По библиотеке можно искать по названию и автору.
- Ридер показывает страницу hayro, текстовый слой, навигацию, кликабельные пункты outline, поиск с выдержками и переходом к совпадению, а также отдельный текстовый режим для текущей страницы.
- Добавлены Inter и переключатель светлой/тёмной темы с сохранением выбора. Тёмный режим инвертирует bitmap страницы.
- Проверен Windows запуск на `C:\Users\kirill\Downloads\Frontend-разработчик.pdf`. В процессе проверки подтверждены локальная копия PDF и созданная обложка. Скриншот окна: `target\liber-nsh.png`.
- Коммиты этапов: `c56d712` (корневой NSH UI), `e3bffb3` (общий PDF/library crate); поиск, текстовый режим и Inter входят в следующий коммит.

## Оставшаяся работа

- Сверил компоновку с GPUI-исходниками предыдущей версии. Общие экраны, Inter, sidebar и ридер перенесены, но цвета, размеры карточек, toolbar и состояния не совпадают пиксель в пиксель. Отдельный GPUI screenshot получить не удалось: чистая GPUI-сборка прошла, запуск завершился сообщением Windows:

  ```text
  error: process didn't exit successfully: `C:\Users\kirill\Coding\kosmos-rs\liber-unified\target\gpui-build\debug\liber-gpui.exe` (exit code: 0xc0000139, STATUS_ENTRYPOINT_NOT_FOUND)
  ```
- Текстовый режим пока показывает извлечённый текст текущей страницы, а не непрерывную книгу. Не перенесены выделения, заметки, аннотации ссылок, режимы Day/Sepia/Gray/Night и дополнительные состояния toolbar.
- Поиск по страницам сейчас выполняется синхронно при вводе. Для больших книг его нужно перевести в фоновый worker и добавить UI-проверку поиска, импорта и перелистывания.
- Обложки сохраняются в размере обычного рендера hayro; переиспользование render cache и тайловый рендер ещё не подключены.

## Запуск из корня

```powershell
nsh run --target windows
```

Выберите PDF кнопкой **Добавить PDF**. Книги, обложки, прогресс и тема хранятся под `%APPDATA%\Liber`.
